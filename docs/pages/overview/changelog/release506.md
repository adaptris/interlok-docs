## Version 5.0.6 ##

Release Date : 2026-05-19

The 5.0.6 release is a small release and is mainly focused on dependency upgrades.

- Added new component entries for connection/error-handling support, including `channel-restart-error-handler`, `channel-unavailable-connection-error-handling-producer`, `configurable-exception-handler`, `exception-rule`, `connection-error-handling-producer`, `regex-exception-matcher`, `solace-connection-state-handler`, `encode-password-service`, `truncate-payload-service`, and `connection-state`.
- Removed optional component `Interlok Messaging/Tibco` (`interlok-tibco`) (interlok-tibco last release is 5.0.5-RELEASE)
